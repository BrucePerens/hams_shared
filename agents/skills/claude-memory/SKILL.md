# Claude Code cross-session memory (committed copy)

The live, harness-read copy of Claude's own persistent memory lives under the dev box's own home
directory (`~/.claude/projects/<encoded-cwd>/memory/`), which does not persist or migrate between
machines -- per `../../docs/CLAUDE_STANDING_CONVENTIONS.md`'s "Repository & persistence
conventions" section, this directory is the durable copy that survives a fresh clone anywhere
else. Each file below is a single self-contained lesson: one topic, a `name`/`description`
frontmatter header, and prose body explaining the lesson and why it matters -- read any of them
directly, or read `../project-experience/SKILL.md` first for narrow, mechanical technical
traps/CI gotchas, which stays a separate, more tightly-scoped log.
